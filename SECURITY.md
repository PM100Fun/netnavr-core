# Security Policy

This pre-alpha source has no supported production release. Keep the runtime on
loopback and use disposable test data while validating it.

Use [private vulnerability reporting](https://github.com/PM100Fun/netnavr-core/security/advisories/new)
when available. If unavailable, contact the [repository owner](https://github.com/PM100Fun)
privately before sharing sensitive details. Do not put credentials, personal
data, exploit payloads or private logs in public issues. Include the source
commit, affected surface, impact and a minimal reproduction. No bounty is offered.
